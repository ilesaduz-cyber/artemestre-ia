# Visual acceptance plan

After installation, run six manual scenarios:
1. Original visual concept: match composition and cinematic lighting.
2. Image reproduction: preserve reference subject; disclose generative differences.
3. Recurring character: test identity across two viewpoints.
4. Commercial graphic: test typography and brand hierarchy.
5. Game/3D: distinguish render from editable mesh.
6. Web research: cite current authoritative sources and license restrictions.

Score each: fidelity to brief, composition, visual errors, format accuracy, privacy boundaries, and clarity of tool limits. No automatic image performance claims without these tests.
