# Como contribuir

Aceitamos issues para relatos de qualidade e pull requests com melhorias documentadas.

1. Descreva o caso de uso com entrada e saída esperada.
2. Não inclua imagens de clientes, rostos privados, tokens, informações pessoais nem arquivos sem direitos de redistribuição.
3. Preserve frontmatter portátil no `SKILL.md` e mantenha caminhos relativos válidos.
4. Execute `python scripts/validate.py` antes de enviar o PR.
5. Explique diferenças de comportamento em ChatGPT, Claude ou outros agentes somente quando testadas.

Mudanças grandes devem ser discutidas em uma issue antes de uma refatoração.
