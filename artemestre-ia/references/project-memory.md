# Gestao de projetos e referencias persistentes

## Regra central

Esta Skill aplica-se a projetos existentes e futuros quando estiver instalada e a tarefa visual for detectada. **Nao** garante acesso a toda conversa antiga, arquivos locais, memoria, bibliotecas, repositorios ou imagens nao fornecidas. Consultar fontes persistentes autorizadas e disponiveis; respeitar a ordem das referencias oficiais.

## Chave de referencia

Usar projeto / personagem ou marca / versao aprovada / origem e localizacao do ativo / caracteristicas imutaveis / variacoes permitidas / data de aprovacao.

Separar, por exemplo, `project-a/character-one`, `project-b/interface`, `brand-x/identity`, `games/title/character`. Nao assumir acesso automatico a esses arquivos.

## Ordem de prioridade

1. Instrucao atual explicita do usuario.
2. Ativo oficial e versao aprovada acessiveis.
3. Referencias de projeto e memoria que descrevam padroes, sinalizando incerteza.
4. Referencias externas para inspiracao, jamais para sobrescrever regras oficiais.

## Governanca

- Ler fontes disponiveis quando necessario, sem alterar dados.
- Antes de gravar, substituir, versionar, publicar, atualizar repositorio ou mudar identidade canônica, obter autorizacao explicita e informar destino/efeitos.
- Nao salvar imagem de pessoa como referencia permanente sem consentimento e nome confirmado quando exigidos pela ferramenta.
- A instalacao da Skill e ato separado do empacotamento; nao a executar por conta propria.
- Documentar diferencas entre 'aprovado', 'candidato' e 'inspiracao'.
